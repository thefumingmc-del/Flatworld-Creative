# Flatworld Creative

Godot project targeting Godot 4.7.2 and landscape Android. Source bundle: Flatworld Creative 0.5.5.

## Build APK

The repository's Android debug workflow runs Godot import/parse and exports an ARM64 debug APK, then publishes the APK as a workflow artifact. This is a development APK, not a Play Store release.

## Status

The 0.5.5 registry/data migration is not yet a verified 1:1 Minecraft Java 26.3 recreation. See the project's registry migration documentation for coverage and remaining gaps.
