# Reference versions and research notes

Requested gameplay reference: **Minecraft Java Edition 26.3**. Requested engine target: **Godot 4.7.2 Stable**.

The Java 26.3 release notes are the reference checklist for the Dappled Forest/poplar content, abandoned camps, explorer map items, cushions, straw beds and the applicable wool/concrete shape families, alongside all established Java mechanics. This project contains a subset of matching themed IDs and simplified behaviour. The presence of a data ID does not mean a feature is complete.

The project uses original GDScript and procedural pixel patterns, not copied Minecraft source code or a bundled copy of Mojang's proprietary asset archive. The licensed cobblestone swatches supplied by the user are kept separately in the texture folder.

## Accuracy note

These sources establish the target version; they are not evidence that this project implements every feature or matches vanilla Java behaviour. Godot parse/runtime checks and Android performance/install tests remain outstanding.
